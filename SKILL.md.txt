Patrón: consecutivo OP con LockService
javascriptfunction generarNumeroOP() {
  const lock = LockService.getScriptLock();
  lock.waitLock(10000);
  const props = PropertiesService.getScriptProperties();
  let consecutivo = parseInt(props.getProperty('ultimo_consecutivo_op') || '0') + 1;
  props.setProperty('ultimo_consecutivo_op', String(consecutivo));
  lock.releaseLock();
  const fecha = Utilities.formatDate(new Date(), 'America/Bogota', 'yyyyMMdd');
  return 'OP-' + fecha + '-' + String(consecutivo).padStart(3, '0');
}
Patrón: calcular días hábiles (festivos colombianos)
javascriptconst FESTIVOS_CO = [
  '01-01','06-01','19-03','01-05','29-06','20-07',
  '07-08','18-08','13-10','03-11','17-11','08-12','25-12'
];
function esDiaHabil(fecha) {
  const dia = fecha.getDay(); // 0=dom, 6=sab
  if (dia === 0 || dia === 6) return false;
  const mmdd = Utilities.formatDate(fecha, 'America/Bogota', 'MM-dd');
  return !FESTIVOS_CO.includes(mmdd);
}

Cómo responder al usuario

Si el usuario describe un bug o mejora con suficiente detalle:
→ Genera el prompt directamente sin preguntar.
→ Al final agrega: "📋 Copia este prompt completo en Claude Code Web."
Si el mensaje es muy vago (ej: "arregla el login"):
→ Haz máximo 2 preguntas puntuales antes de generar el prompt.
→ Ejemplo: "¿El error es que no valida las credenciales,
o es que no redirige al dashboard después de ingresar?"
Si son múltiples mejoras en un solo mensaje:
→ Genera un prompt separado por cada mejora.
→ Ordénalos por prioridad: 🔴 primero, luego 🟡, 🟢, 🔵, 🟣.
→ Indica el orden recomendado de ejecución.
Siempre termina tu respuesta con:
"💡 Tip: ejecuta este prompt en Claude Code Web con el archivo
CLAUDE.md presente en el repositorio para dar contexto completo."
